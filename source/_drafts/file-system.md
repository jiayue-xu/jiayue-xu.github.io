## 文件系统的基本组成

文件系统是操作系统中负责管理持久数据的子系统，它的基本单位是文件，文件存储在磁盘上，不同的文件组织方式对应不同的文件系统。

Linux文件系统会为每个文件分配两个数据结构：索引节点（inode）和目录项（directory entry）。

- inode：是文件的唯一标识，与文件一一对应，同样存储在磁盘中，记录文件的元信息，inode编号、文件大小、访问权限、创建时间、修改时间、数据在磁盘的位置等。
- dentry：记录目录层次结构，文件名字、inode指针、与其他目录项的层级关系，目录项由内核维护，不存放在磁盘，缓存在内存中。
- dentry与inode是多对一的关系

目录项（dentry）与目录：目录是一个文件，持久化存储在磁盘，目录项是一个数据结构，缓存在内存。

### 磁盘

磁盘读写的最小单位是**扇区**，为了提升读写效率，文件系统把多个扇区组成了一个逻辑块，每次读写的最小单位就是逻辑块，Linux逻辑块大小为4KB。

对磁盘进行格式化时，会将其分为三个存储区域，分别为：超级块、索引节点区、数据块区。

- 超级块：存储文件系统的详细信息，比如块个数、块大小、空闲块等。当文件系统被挂载时，超级块被载入内存。
- 索引节点区：存储索引节点。当文件被访问时，对应的索引节点被载入内存。
- 数据块区：存储文件或目录数据

## 虚拟文件系统

操作系统在用户层与文件系统层中引入了虚拟文件系统（VFS），用于抽象不同种类的文件系统。

VFS定义了一组所有文件系统都支持的数据结构和标准接口。

Linux支持的文件系统根据存储位置的不同可以分为三类：

- 磁盘的文件系统：直接把数据存储在磁盘中，比如EXT、XFS等。
- 内存的文件系统：数据存放在内存中，比如/proc与/sys文件系统等，读写这类文件实际上是在读写内核中相关数据。
- 网络的文件系统：访问其他计算机主机数据的文件系统，比如NFS、SMB等。

文件系统首先要先挂载到某个目录才可以正常使用，比如Linux系统在启动时，会把文件系统挂载到根目录。
